# Katalog Karya - Latihan P10

Latihan Detektif Bug pada mata kuliah Praktikum Pemrograman Visual (TB033109).
Enam bug (G1 sampai G6) diperbaiki pada cabang `fix/katalog`. Proses
pengerjaannya dicatat di [DEBUG_LOG.md](DEBUG_LOG.md).

## Cara menjalankan

Buka berkas `index.html` di browser (Chrome atau Edge).

## Struktur berkas

- `index.html`: halaman katalog karya
- `data.js`: data karya
- `main.js`: proses render kartu, pencarian, filter, dan detail
- `assets/logo-katalog.svg`: logo pada navbar

## Catatan bantuan AI

AI digunakan untuk membantu menyusun kode dan perbaikan bug, sedangkan setiap perbaikan tetap diuji ulang melalui DevTools sebelum di-commit.
